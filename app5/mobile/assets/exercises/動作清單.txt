伸展動作庫：100 個內容單位，每個 30 秒
以下含同一活動的姿勢變體，並非全部都是靜態伸展。

- 手 / 前臂屈伸肌群 / 仰躺手腕勾放 (lie_wrist_flex)
  上臂支撐在身旁、前臂朝上，手腕小幅前後活動。
  語音：0s「上臂放穩，前臂朝上，手腕輕輕勾放。」；10s「只動手腕就好。」；15s「繼續小幅度活動，雙手不要靠近臉。」；22s「放鬆手腕，慢慢放下。」

- 手 / 前臂屈伸肌群 / 坐姿手腕左右 (sit_hand_wave)
  手腕小幅左右擺動，像慢速揮手。不上下甩。
  語音：0s「手腕慢慢左右擺。」；10s「前臂留在腿上。」；15s「繼續慢一點。」；22s「手掌回正。」

- 手 / 前臂屈伸肌群 / 坐姿掌心翻轉 (sit_palm_turn)
  手背先放著，再把拇指轉向上、掌心翻轉，然後回到手背向下。左右一起或輪流都可以。
  語音：0s「掌心慢慢轉向上。」；10s「停一下。」；15s「再轉回手背向下。」；22s「雙手放鬆。」

- 手 / 前臂屈伸肌群 / 坐姿手腕伸放 (sit_wrist_ease)
  另一手把手腕輕輕托向上，再放開，讓手腕自己慢慢向下。換手。不要壓痛。
  語音：0s「左手輕托右手腕向上。」；10s「放開，讓手腕慢慢向下。」；15s「換邊，再托一次。」；22s「兩手放下。」

- 手 / 前臂屈伸肌群 / 手腕上下活動 (sit_wrist_flex)
  前臂支撐在腿上，手腕小幅向上、向下活動。
  語音：0s「前臂放穩，手腕輕輕往上抬，再放下。」；10s「小小活動，不用彎到底。」；15s「繼續慢慢上下活動，手臂保持放鬆。」；22s「回到自然位置，休息一下。」

- 手 / 前臂屈伸肌群 / 坐姿手腕上抬 (sit_wrist_hold)
  輕輕握拳，把手抬到與前臂接近同一直線，停一下再放鬆，然後換手。
  語音：0s「右手輕握，抬到與前臂平齊。」；10s「停一下再放鬆。」；15s「換左手，同樣抬起。」；22s「兩手放下。」

- 手 / 前臂屈伸肌群 / 站姿手腕活動 (stand_wrist_flex)
  雙肘彎曲靠身旁，手腕小幅向上、向下活動。
  語音：0s「雙肘靠身旁，手腕輕輕往上，再往下。」；10s「小幅度就好。」；15s「繼續慢慢活動，別用力彎到底。」；22s「放鬆手腕，雙手放下。」

- 手 / 手指屈伸肌群 / 仰躺手指開合 (lie_finger_open)
  雙臂放在身旁，雙手輕握拳再張開手指。
  語音：0s「雙手放身旁，輕輕握拳，再張開手指。」；10s「慢慢來，不用握緊。」；15s「繼續輕輕開合，肩膀保持放鬆。」；22s「停下，放鬆雙手。」

- 手 / 手指屈伸肌群 / 坐姿手指鉤放 (sit_finger_hook)
  手指先彎成鉤子，再慢慢伸直。動作要小。
  語音：0s「手指輕輕彎成鉤狀。」；10s「再慢慢伸直。」；15s「再鉤一次。」；22s「雙手放下。」

- 手 / 手指屈伸肌群 / 坐姿指節彎曲 (sit_finger_mid)
  彎曲手指中間的關節，指尖朝向掌心的方向，再伸直。
  語音：0s「中間指節慢慢彎曲。」；10s「再伸直。」；15s「再彎一次。」；22s「手指放鬆。」

- 手 / 手指屈伸肌群 / 手指輕開合 (sit_finger_open)
  前臂放在腿上，雙手輕握拳再張開，慢慢重複。
  語音：0s「前臂放在腿上，輕握拳，再張開手指。」；10s「慢慢開合，不用握緊。」；15s「繼續照自己的速度，輕輕張開再放鬆。」；22s「停下來，放鬆雙手。」

- 手 / 手指屈伸肌群 / 坐姿手指張開 (sit_finger_spread)
  手指慢慢向兩側張開，再併攏。不需要握拳。
  語音：0s「手指慢慢向兩側張開。」；10s「再輕輕併攏。」；15s「繼續張開、併攏。」；22s「手指放鬆。」

- 手 / 手指屈伸肌群 / 坐姿指尖彎曲 (sit_finger_tip)
  只彎指尖的關節，再伸直。其他指節盡量保持放鬆。
  語音：0s「只彎指尖，再伸直。」；10s「其他關節放鬆。」；15s「再彎一次指尖。」；22s「手指打開。」

- 手 / 手指屈伸肌群 / 坐姿手指平握 (sit_flat_fist)
  指根彎曲，指尖與中間關節保持較直，做成平平的握姿，再打開。
  語音：0s「指根彎曲，指尖保持伸直。」；10s「再打開。」；15s「再做一次平握。」；22s「手指放鬆。」

- 手 / 手指屈伸肌群 / 站姿手指開合 (stand_finger_open)
  雙肘靠近身旁，手指輕握再張開，慢慢重複。
  語音：0s「雙肘靠身旁，雙手輕握，再張開手指。」；10s「不用握緊，慢慢來。」；15s「繼續輕輕開合，肩膀保持放鬆。」；22s「放鬆雙手，慢慢垂下。」

- 手 / 拇指肌群 / 坐姿拇指外展 (sit_thumb_out)
  拇指慢慢向外打開，再收回來。
  語音：0s「拇指慢慢向外打開。」；10s「再收回來。」；15s「再打開一次。」；22s「拇指放鬆。」

- 手 / 拇指肌群 / 坐姿拇指輕彎 (sit_thumb_tip)
  只彎拇指的指尖，再伸直。
  語音：0s「拇指指尖輕輕彎一下。」；10s「再伸直。」；15s「再彎一次。」；22s「拇指放鬆。」

- 手 / 拇指肌群 / 坐姿拇指對指 (sit_thumb_touch)
  拇指依序輕點食指、中指、無名指與小指的指尖，每點一次就把拇指伸直。
  語音：0s「拇指輕點食指，再伸直。」；10s「接著點中指、無名指。」；15s「再點一下小指。」；22s「拇指伸直。」

- 手臂 / 三頭肌 / 坐姿手臂後側伸展 (sit_triceps)
  坐直，左肘向上彎，右手輕扶。；回正放下後換另一手。
  語音：0s「坐直，左肘向上，右手輕扶。」；10s「肩膀放鬆，不用力壓。」；15s「雙手放下，再換右肘向上。」；22s「雙手放回腿上。」

- 手臂 / 三頭肌 / 頭上手臂後側伸展 (stand_triceps)
  左肘朝上彎曲，右手輕扶左肘。；輕靠近頭部，回正後換手。
  語音：0s「左手抬高彎肘，右手輕扶左肘。」；10s「保持呼吸，不要壓頸部。」；15s「放下換手，左手輕扶右肘。」；22s「慢慢放下雙手。」

- 手臂 / 二頭肌與三頭肌 / 仰躺手肘彎伸 (lie_elbow_bend)
  上臂放在身旁，前臂慢慢抬起再放回，手肘不鎖直。
  語音：0s「上臂留地，彎手肘，前臂抬起再慢慢放下。」；10s「不用把手碰到肩膀。」；15s「繼續輕輕彎伸，肩膀保持放鬆。」；22s「慢慢放下雙手，休息一下。」

- 手臂 / 二頭肌與三頭肌 / 手肘輕彎伸 (sit_elbow_bend)

  語音：0s「手臂放身旁，彎手肘，雙手靠近肩膀。」；10s「再慢慢放下，不要甩手。」；15s「繼續輕輕彎曲，再慢慢伸回。」；22s「雙手放下，放鬆手臂。」

- 手臂 / 二頭肌與三頭肌 / 站姿手肘彎伸 (stand_elbow_bend)

  語音：0s「彎曲手肘，雙手慢慢靠近肩膀，再放下。」；10s「上臂留在身旁。」；15s「繼續慢慢彎伸，不用伸得很直。」；22s「雙手放下，放鬆手臂。」

- 手臂 / 肘關節肌群 / 坐姿手肘伸直 (sit_elbow_long)

  語音：0s「右肘輕輕伸直，掌心向上。」；10s「肩膀放鬆。」；15s「換左肘，輕輕伸直。」；22s「兩手放回腿上。」

- 肩 / 肩帶肌群 / 仰躺雙臂上舉 (lie_arm_overhead)

  語音：0s「兩手輕握，舉到身體上方。」；10s「只到舒服的高度。」；15s「再舉一次，然後慢慢放回。」；22s「雙手放到身前。」

- 肩 / 肩帶肌群 / 仰躺手肘外開 (lie_elbow_open)

  語音：0s「雙臂貼著墊面慢慢向上滑。」；10s「腰背留在墊上。」；15s「再滑一次，不要硬壓。」；22s「雙臂滑回身側。」
